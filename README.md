# 己镜 · 遇见自己，拥抱自己

> 一款关于**自我认知、情感陪伴、积极生活**的 App。

**[▶ 观看产品介绍片（28 秒 · 竖屏 1080×1920）](jijing-intro-20261106-v11.mp4)**

每个人的心里，都住着一面镜子。
只是很多时候，我们忘了停下来，好好照一照自己。

「己镜」想做的，是陪你把这一面镜子擦亮——
照见自己的心性底色，照见这段时光里的风景，也照见身边重要的人。

**己镜——遇见自己，拥抱自己。**
不给你贴标签，而是陪你走过每一段时光：了解自己的性格与节奏，在低落时被温柔接住，在寻常日子里找到属于自己的方向。

---

## 你可以用己镜做什么

### 一、遇见自己 · 自我认知

- **初度之辰** —— 定格初见，照见先天心性底色。第一次打开己镜，从认识自己的底色开始。
- **遇见自己** —— 八维侧写，照见心性轮廓。
- **知己之境** —— 随心之题，照见真实本我。
- **时光轨迹** —— 铺展长卷，阅尽流年光景。你的每一步，都值得被看见、被记住。

### 二、拥抱自己 · 情感陪伴

- **心之微澜** —— 记录心绪，放松倾听自己。每天的喜怒哀乐，都被记录。
- **解忧小筑** —— 投递心事，静候温柔回音。说不出口的话，可以放在这里。
- **晨光锦字** —— 每日晨起，一封予你信笺。开始新的一天前，先收一句温暖。

### 三、照见生活 · 日常与连接

- **见远择吉** —— 顺心择日，寻得岁月良辰。把重要的日子，安放在顺心的时刻。
- **字蕴五行** —— 拆解字源，丈量名字分量。一个名字里，藏着怎样的期许与力量。
- **名荐天成** —— 百名甄选，五行称量佳名。为即将到来的新生命，挑一个承载祝福的名字。
- **琴瑟和鸣** —— 双心合盘，窥探缘分深浅。懂你，也懂你在乎的人。
- **爻动知几** —— 一事一问，洞见万物先机。心里有放不下的事，来这里问一问。

## 关于这支介绍片

全片 28 秒，竖屏 9:16，无旁白，只有音乐与音效。

片子的骨架不是功能罗列，而是产品的名字本身：全片只有一条水平镜线。「每个人的心里／都住着一面镜子」两列竖排大字从满幅回落、沉进镜面；接着「己镜」两个字从同一片水里升起来（水下是虚的，出水才清晰）；名字沉回去的下一拍，App 首页从同一个水面升出、底边停在镜沿，在水下留一道倒影，镜头随即推进去，同一张卡变成第一个展示帧。

素材全部来自 App Store 商店图与《产品介绍.md》，未做界面重绘。音乐是照 12 小节现写的国风曲子：D 宫调式、100 BPM、古筝主奏，快切那一段一刀一记鼓点。
